# 环境监测与污染物堆专属地图设计

**日期：** 2026-09-15

## 目标

在主地图中仅为环境监测装置和污染物堆增加独立地图入口，使用“通用场景 + 地图配置”实现；其余交互点保持现有主地图逻辑。

## 范围

### 新增专属地图

- `interaction.monitoring_device_01` → `map.environment_monitoring_01`
- `interaction.pollution_zone_01` → `map.pollution_cleanup_01`

### 保持主地图交互

- 排水设施
- 暴雨冲散垃圾
- 受损环境点（已有环境修复专属场景，不在本次改造范围内）
- 生态巡查点
- 雾天危险点
- 林工、巡查员 NPC

## 交互规则

### 环境监测装置

玩家在主地图靠近环境监测装置并按 E 后进入环境监测专属地图。专属地图暂使用占位视觉，但必须保存来源场景、交互点 ID 和返回位置；按 ESC 返回主地图。

### 污染物堆

污染物堆继续服从现有清理任务状态：

- 没有清理任务或任务不可进行：留在主地图显示现有提示。
- 清理任务为 active：进入污染物处理专属地图。
- 清理任务已完成：留在主地图显示“已完成”提示，不重复进入。

污染地图完成或返回时不得重置任务 Store、环境 Store 或主地图污染物视觉状态。

## 架构

新增通用专属地图上下文，至少包含：

- `sourceSceneKey`
- `sourceMapId`
- `interactionId`
- `targetMapId`
- `returnPosition`

新增地图配置注册表，地图配置包含地图 ID、场景 key、显示名称、地图类型、来源交互点、出生点和占位状态。

环境监测和污染物处理各自使用通用专属场景类，具体内容由 `targetMapId` / `interactionId` 配置驱动。已有环境修复场景保持兼容，不要求本次迁移。

## 素材策略

第一阶段使用占位背景、占位地面和占位交互设备完成流程验证。正式素材在代码侧明确资源入口后再接入，不在本次范围内虚构素材文件。

## 验收标准

1. 环境监测装置可以从主地图进入监测专属场景并返回原位置。
2. 污染物堆仅在清理任务 active 时进入污染处理专属场景。
3. 没有任务或任务完成时，污染物堆维持原主地图反馈逻辑。
4. 其余交互点行为不改变。
5. 地图上下文不会串线，返回后主地图状态不被重置。
6. 配置和路由有单元测试，现有测试和构建通过。
