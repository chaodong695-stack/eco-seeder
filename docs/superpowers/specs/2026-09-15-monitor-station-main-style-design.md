# 工业监测站主界面风格示例设计

日期：2026-09-15

## 目标
制作一个独立的浏览器视觉示例，不修改现有 React/Phaser 源码。示例以 `public/assets/images/用户附件.png` 为全屏背景，完整保留工业监测站照片，并借用 StartPage 的深蓝黑色渐变、浅色宽字距标题、薄荷绿色强调色和简洁 HUD 语言。

## 视觉构成
- 背景：图片使用 `object-fit: cover`，完整覆盖视口；增加左侧较强、底部适中的深色渐变和内阴影暗角，保持右侧夕阳与水面可见。
- 品牌标题：左上区域显示 `ECO SEEDER`、`生态播种者`、`水质监测站` 和短描述，避免覆盖中央监测屏幕。
- HUD：右上展示 `SECTOR 01`、`WS-01`、`LIVE MONITORING`；底部展示环境状态和“点击监测屏幕查看数据”的提示。HUD 为展示文本，不是按钮。
- 唯一交互：一个透明/半透明的薄荷绿色热点覆盖照片中的中央监测显示器，文案为“打开监测数据”。按钮带细边框、微光和 hover 状态。不得在其他位置增加可点击按钮。
- 数据面板：点击屏幕热点后，在屏幕附近出现非全屏的半透明 HUD 面板，展示示意性的 pH、DO、浊度和温度数据；用关闭/返回控件收起面板。该控件属于监测屏幕交互区域的一部分。

## 交互与响应式
- 初始状态展示完整场景和 HUD。
- 点击监测屏幕按钮切换数据面板；再次点击关闭控件恢复初始状态。
- 面板定位使用相对背景的百分比坐标，窗口缩放时随场景移动；小屏幕上面板改为底部浮层，按钮仍保持在屏幕区域。
- 支持 `prefers-reduced-motion`，关闭背景缩放和 HUD 呼吸动画。

## 输出与边界
- 新增独立示例文件到 `.superpowers/brainstorm/.../content/`，通过视觉伴侣服务器预览。
- 如需复用图片，示例引用项目内 `/assets/images/用户附件.png`，不复制或修改原图片。
- 不修改 `src/`、`package.json` 或现有页面逻辑。
- 所有数值均标记为演示数据，不表示真实监测结果。

## 验收标准
1. 页面可在本地浏览器打开并正确加载原图。
2. 照片主体和构图仍然清晰可辨，夕阳与监测设备不被过度遮挡。
3. 标题、渐变和 HUD 视觉上接近 StartPage。
4. 初始页面除监测屏幕外没有其他按钮。
5. 点击屏幕后能展示并关闭示意数据面板。
6. 在桌面和窄屏尺寸下没有明显溢出或错位。
