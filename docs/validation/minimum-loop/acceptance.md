## 浏览器实测

使用正常 WASD 移动、E 交互、NPC 接任务和 React 操作按钮，未直接修改治理 Store 或传送角色。

1. 首页选择角色，前往林工接取固定治理委托。
2. 进入环境监测装置，错误方案不推进；提前释放不推进；正确方案持续执行建立基线。
3. 从主地图进入污染物处理区，完成废水设施和泄漏管线两个点位。
4. 从两个受损环境点分别进入修复区，完成土壤与水岸修复。
5. 回到环境监测装置复测，出现六项完成的治理报告。
6. 返回主地图可见污染源及两个受损点的完成标识；重入已完成区域不能重复执行。
7. 中途返回首页并刷新继续保留四项成果；完成后刷新继续保留六项成果、角色和快照。
8. 取消新游戏保留六项成果；确认新游戏并选择角色后清空治理进度。
9. 新局再次经普通入口完成全链，确认快照写入存档。模拟结果：污染 78→18、植被 22→77、水质 30→90、修复进度 0→100。
10. 键盘 Space 持续执行与鼠标 pointer 持续执行均可推进；组件测试覆盖提前释放和窗口失焦中止。
11. 宽屏和 540×800 窄屏检查，点位列表、方案和执行按钮可操作；监测场景视频播放中，原视频尺寸为 1280×720。

## 范围与限制

这是首轮任务的最小闭环，结算后支持保留成果和继续探索。后续关卡、循环经济、消耗品、动态污染扩散及更深策略尚未扩展。视频用于场景背景，实际操作使用点位列表；环境指标为游戏模拟值。进度保存在当前浏览器的 localStorage，跨浏览器或清理站点数据不会迁移；写入失败有提示，同页保留内存进度。
