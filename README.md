# Eco Seeder

一款以环境保护为主题的网页养成游戏。玩家通过完成生态治理任务、与 NPC 互动、恢复区域生态环境，逐步了解污染治理、资源循环和可持续发展的基本知识。

## 当前阶段

## 开发原则

1. 需求文档、接口文档和代码同步维护。
2. 页面、游戏逻辑、数据层和外部服务解耦。
3. 所有功能通过独立分支开发，并通过合并请求进入主分支。
4. 优先完成可运行的 MVP，再逐步补充动画、NPC 智能和高级视觉效果。
