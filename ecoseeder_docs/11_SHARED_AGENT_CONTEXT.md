# 《生态播种者》共享 Agent 上下文

## 1. 项目概要

你正在协助开发《生态播种者》v0.1。这是一款轻科幻公益生态修复 Web 游戏。玩家在未来污染城市中完成清理、监测、种植、救助、避险与轻量建设任务。

当前首张地图：

```text
map.urban_wasteland
```

技术栈：

- React
- TypeScript
- Vite
- Phaser 3
- Zustand
- Vitest
- CNB.cool

---

## 2. 核心规则

1. 天气是游戏内部模拟，不接真实天气 API。
2. 昼夜默认依据真实设备时间。
3. AI 不决定游戏结果，只提供科普、风险和复盘。
4. 规则引擎决定状态变化、分数、奖励和副本成败。
5. 玩家保留最终选择权。
6. 同一选择在不同环境下产生不同结果。
7. 地图、任务、副本、NPC、天气和奖励必须配置化。
8. React 负责 UI，Phaser 负责场景。
9. mock 社交和 mock AI 必须通过接口实现。
10. 不为了 MVP 把内容写死。
11. 任何 Agent 在处理地图、人物、NPC、机器人、UI、图标、特效或美术资源前， 必须先阅读 `14_ART_DIRECTION_BIBLE_v0.1.md`。 Agent 不得将 AI 生成的完整游戏截图直接作为正式地图资源， 不得自行改变既定美术方向。

---
### 3. 场景实现口径

v0.1 是 Phaser 3 二维游戏。

2.5D 仅指视觉表现，第三人称仅指玩家角色在场景中可见。
所有移动、碰撞和交互使用二维系统。

Agent 不得引入 Three.js、真实 3D 模型或三维物理系统。

## 4. v0.1 内容

- 20—30 秒概念视频；
- 男性和女性角色选择；
- 1 张完整主地图：雾港旧工业区；
- 5 个地图区域；
- 真实昼夜；
- 模拟天气；
- 6 个日常任务配置；
- 8 个随机任务配置；
- 3 名实际投放 NPC；
- 1 个保留配置接口的 NPC 职业原型；
- 1 个完整副本：受伤动物救助；
- 2 个简化触发演示：暴雨垃圾扩散、地下排水站；
- AI 短提示、咨询和复盘；
- 好友协助与生态广场 mock；
- 奖励和评级。

---
### 5. v0.1 副本范围

v0.1 保留三个副本或特殊事件入口，但完成度不同：

- `animal_rescue`：受伤动物救助，完整副本；
- `storm_waste_spread_demo`：暴雨垃圾扩散，简化触发演示；
- `drainage_station_demo`：地下排水站，简化触发演示。

Agent 不得将后两个演示事件扩展为完整副本。

简化演示必须能够真实触发、完成至少一个交互并返回结果，
不能只创建不可点击按钮或纯文字占位。

v0.2 内容不属于当前 Agent 的默认任务范围。

### 6. NPC 范围

设计层共有 4 种 NPC 职业原型。

v0.1 只制作和投放 3 名主要 NPC：
环境监测员、当地居民或环保志愿者、生态修复工程人员。

第 4 种职业原型只保留配置接口。
Agent 不得自行增加第四名正式 NPC 或扩大 NPC 资产范围。

## 7. 视觉方向

```text
半写实数字绘景风格
+ 2.5D 游戏空间表现
+ 写实污染材质
+ 温和近未来生态科技
```

避免：

- 纯赛博朋克霓虹
- 过于卡通的低龄画面
- 满屏网页卡片
- UI 文字烘焙进场景图
- 直接复制现有游戏风格

---

## 8. 代码要求

- TypeScript strict
- 模块解耦
- 公共接口有文档
- 内容使用 schema 校验
- 领域逻辑可测试
- 外部服务可替换
- PR 包含测试和截图
- 不改动无关模块
- 不在组件中写任务和奖励规则

---

## 9. 输出要求

在执行任何开发任务前：

1. 阅读相关文档；
2. 明确受影响模块；
3. 说明接口变化；
4. 给出最小实现方案；
5. 保留后续扩展；
6. 完成后运行类型检查、测试和构建；
7. 更新文档。

遇到需求冲突时，以以下优先级判断：

```text
可运行性
> 规则正确性
> 架构可维护性
> 视觉一致性
> 功能数量
```
